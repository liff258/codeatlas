# 演示分镜（知识平台版）

> 目标：6 分半内让评委记住一句话——
> **"文档是线性的，知识是网状的；而这个网里最值钱的是跨域的那几条线。"**
>
> 产品形态已经变了：不再是"打开就是输入框"，而是"先给结构，再给追问的出口"。
> 所以分镜也必须变——**从「逛」开场，用「跨域」收尾**。

## 录制前 3 分钟（不录）

1. 起服务：数据库(5433) → Python(8000) → Java(8080) → 前端(5173)
2. **清一次 localStorage**：控制台执行 `localStorage.clear()` 再刷新。
   我们做了对话持久化，不清的话开场会直接显示上次的对话，不是首页。
3. **预热**：先在对话页问一句无关的话（如"你好"），让三个本地模型加载完。
   冷启动 25 秒，录进去很难看。
4. 窗口 1920×1080，浏览器缩放 100%，关掉其他标签和通知。
5. 提前跑一遍主线，确认今天模型不抽风（免费额度会排队）。

## 意外情况应对

| 情况 | 现象 | 怎么说 / 怎么做 |
|---|---|---|
| **模型限流（429）** | 思考面板出现黄色"模型限流" | 别慌："这就是降级——它重试两次后改用兜底，继续把答案给你。" |
| **模型超时** | 节点黄色，"模型响应超时（10s）" | "免费额度下延迟波动大，所以每个节点都设了超时和兜底。"**别说"网络问题"** |
| **图谱没边** | 图上只有点没线 | "这题的概念在库里没有共现，所以没连边——没有关系就不画关系。" |
| **点节点没反应** | 点击后没跳转 | 节点半径小，鼠标落在圆点上再点。**别连点三次**，会被看出是碰运气 |
| **答案没出表格** | 模型这次没写表格 | 不重跑："格式由模型自己决定，我只约束了引用必须可溯源。" |
| **助手抽屉空白** | 打开后没内容 | 正常，它是空态引导；点一个提示词就能用 |
| **整页空白** | 路由跳错 | 地址栏手动改 `#/` 回首页，别在录屏里刷新 |

## 录制注意

- **一定要先 `localStorage.clear()`**。我们做了对话持久化，不清的话开场不是首页。
- **不要用小窗口录**，图谱会挤成一团。1920×1080。
- 鼠标轨迹要慢。指向跨域虚线时**停 1 秒**再说话。
- 台词别背，按要点说，允许口语化——背稿听起来像念稿。
- 等答案基本出完再讲下一段，别边等边说。
- 主线题如果这次答得不好（模型波动），**重跑再录**，不要剪。

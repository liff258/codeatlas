# jieba 用户词典：计算机领域术语
#
# 为什么需要这份文件：
#   jieba 的默认词典是通用语料训练出来的，"红黑树" 这种词它不认识，
#   会切成 "红" "黑树"，或者在某些句子里切成 "比红" "黑树快"。
#   分词一错，BM25 的召回直接塌——因为这些词恰恰是区分度最高的检索信号。
#
# 格式：词语 词频 [词性]。词频给高值，确保切分时优先按整词识别。
# 维护原则：只收「会被切错」或「切开就失去意义」的词，不要无脑堆砌。
